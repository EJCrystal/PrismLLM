# 诊断插件生命周期不变量

## 单一所有者与验收条件

| 失败族 | 不变量 | 状态所有者 |
| --- | --- | --- |
| 准入与停用历史 | 已提交停用永远不能被旧进程的重新启用覆盖；未发送执行的准入等待有期限并归还全部名额。 | 安装 CAS 保存停用代次；每个已加载实例固定其加载代次；宿主拥有不可重开的准入锁存。 |
| 凭据归属与恢复 | 提供方交换最多执行一次；已取得的轮换结果必须保留到保存成功或确认凭据被替换；正常轮换链成员不是管理员替换。 | OAuth 刷新任务拥有保留的密文结果和轮换记录；调用方仅持有绑定快照。 |
| 数据库期限与资源 | 租约在代理交付前的每条失败路径都由当前所有者释放；锁等待、业务查询与清理各有有界预算。 | JDBC 连接所有权交接、现有诊断期限以及事务局部锁超时。 |
| 当前界面上下文 | 只有当前上下文、当前请求和稳定入口 ID 可以更新界面或获得焦点；测试必须证明请求真正发出或确实进入等待。 | 每个组件的上下文／请求代次及稳定页签 ID；不增加跨请求缓存。 |

## 事件 × 状态

| 事件 | 待准入／准备中 | 已加载且准入 | 已关闭／已过期 |
| --- | --- | --- | --- |
| 停用开始 | 临时拒绝新调用，等待中的调用不能发送。 | 增加已有停用计数，先挡住新调用。 | 不重开。 |
| 停用 CAS 成功 | 代次递增；再次复核拒绝发送。 | 永久关闭旧实例准入。 | 保持关闭。 |
| 停用 CAS 失败或取消 | 限时确认已提交状态；未知结果按关闭处理。 | 只有确认原代次与允许状态未变时才解除临时阻止。 | 不逆转已观察到的关闭。 |
| 跨实例停用后重新启用 | 即使漏读中间状态，也按代次不匹配拒绝。 | 旧加载代次不变；需重启加载。 | 启用只改期望状态。 |
| 同版本配置更新 | 后续新调用读取配置。 | 准入代次不变，配置立即更新。 | 不借配置更新重开。 |
| 凭据／授权在慢准备中改变 | 在准备后复核原身份、当前权限及请求配置；不发送。 | 已发出的 HTTP 不承诺撤回。 | 迟到结果不得恢复准入。 |
| 取消、超时或连接代理初始化失败 | 归还执行名额、探测名额与未交付连接。 | 已移交资源只由接收方清理。 | 重复清理无副作用。 |
| 数据库恢复 | 对已有保留密文执行有界保存机会，不重新交换提供方令牌。 | 成功保存后释放已有任务容量。 | 管理员替换的结果不回写。 |
| 停机保存首项被锁 | 总期限内保留其他账号的保存机会。 | 停止新交换，继续已有结果的有界清理。 | 不将迟到结果发布给旧等待者。 |
| 发现响应重排页签 | 按事先保存的入口 ID 恢复焦点。 | 当前选择存在才保留，否则按现有优先级回退。 | 已卸载请求不得通知或写入界面。 |
| 上下文切换或目录项消失 | 取消旧请求，清空旧结果、错误和不再有效的选择。 | 不把旧上下文响应视为新上下文数据。 | 旧请求保持失效。 |

## 判别性回归

- 宿主：未观察中间停用的第二运行时、卸载后恢复、启动发布前停用循环、配置立即生效，以及初次／最终准入超时后的名额恢复。
- PostgreSQL：独立运行时和连接共享同一安装记录，核对 CAS 保存的停用代次、卸载恢复、锁等待与连接交接清理。
- HTTP：在确实进入宿主互斥锁队列后检查零上游；在慢设置／令牌准备期间撤销模型、账号绑定、准确凭据或插件权限后检查拒绝发送。
- 界面：键盘导航与发现重排交错、目录项移除、同账号授权上下文更新，以及确认保存请求仍在等待后卸载。

验收仍要求同一最新 HEAD 的代码 CI、成功完整最终复审及所有受保护门禁；历史已解决线程或部分复审不能替代它们。
