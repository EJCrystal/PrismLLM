# 管理界面按当前名称展示调用方密钥、渠道与渠道密钥

## 背景

请求日志写入时保存 client_key_name、channel_name、channel_key_name 快照。实体改名后，报表筛选使用当前名称，而报表分组和日志详情仍显示旧快照，同一实体在管理界面出现两个名称。

## 决策

管理面的用量报表和请求日志读取时，按 client_key_id、channel_id、channel_key_id 关联当前配置并返回当前名称；实体已删除或名称为空时回退到请求日志中的快照。请求日志中的快照列保持不变，不改写历史数据。

## Consequences

- 改名后报表、CSV 和请求日志详情统一显示新名称，无需回填历史日志。
- 实体删除后仍能通过快照显示原名称。
- 原始快照仍保留在 request_logs 中，供审计或后续需要时使用。
- 调整 ADR 0006 和 ADR 0007 中名称快照的展示约定，名称快照的存储策略不变。
