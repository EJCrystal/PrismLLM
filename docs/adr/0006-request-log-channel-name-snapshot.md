# 请求日志保存渠道名称快照

请求日志同时保存 `channel_id` 和请求发生时的 `channel_name`。列表显示名称，详情同时展示名称和 ID。

## 理由

日志是历史记录，而渠道可以改名，也可能被删除。只保存 `channel_id` 会让列表在改名后显示新名称，历史记录失真；渠道删除后则只剩一串 UUID。写入时保存名称快照，既能让列表直接可读，也能保留当时的真实路由目标。

## Consequences

- 渠道改名只影响之后的请求，历史日志保留当时的名称。
- 删除渠道后日志仍然可读；`channel_id` 用于精确关联当时的渠道。
- 路由阶段失败的请求没有选中渠道，两个字段都为空。
