# 系统提示词

在管理台的「系统配置 → 系统提示词」统一管理规则。默认关闭且没有规则，不会改变已有请求。编辑完毕后统一保存，保存成功后对新请求和新发起的连通性测试生效；在途请求继续使用开始时取得的配置快照。

## 生效范围与匹配

- 全局：所有正常对话及连通性测试。
- 出口协议：选择一个或多个 Messages、Chat Completions、Responses、Gemini 出口。
- 渠道：选择一个或多个渠道。
- 渠道与出口协议：请求必须同时属于选定渠道和选定出口协议。

协议按转换后实际发送给上游的协议匹配，而不是客户端的入口协议。例如 Messages 请求转换为 Gemini 出口时，匹配 Gemini 规则。

优先顺序固定为「渠道＋协议 > 渠道 > 协议 > 全局」。同层级优先级数值越大越优先；同分时按列表顺序，首条命中生效。上移、下移可调整同分规则的顺序。一次请求只选择一条规则，不拼接多条提示词。

规则可选择「替换系统提示词」或「不覆盖」。「不覆盖」用于豁免更宽泛的规则，保留该请求原有处理链，包含已有的通用请求体覆盖和兼容性处理。停用某条规则则跳过它，仍可能匹配其他规则。

渠道删除后，其 ID 不会自动清空或变成全局匹配。编辑器会标记失效渠道，需要移除或重新选择后才能保存。

## 替换行为

命中替换规则时，专用系统提示词策略在通用请求体覆盖之后执行，其正文优先于通用覆盖中的系统提示词字段：

| 出口协议 | 修改范围 |
| --- | --- |
| Messages | 替换顶层 system，包括旧文本块与其中的缓存元数据 |
| Chat Completions | 移除 system/developer 消息，在开头放入一条新的 system 消息 |
| Responses | 替换 instructions，移除当前 input 数组中的 system/developer 消息 |
| Gemini | 替换 systemInstruction 的全部内容 |

正文保留原始空白与换行，不与客户端提示词拼接；显式替换后的 Code Assist 请求不再经旧 cloak 改写。用户、助手、工具消息及工具定义不受该策略改写。这里只修改当前请求，不修改服务端保存的历史会话。

**整段替换会丢弃客户端原有的系统级工具使用指导、编码约定及行为要求。** 使用 ZCode、Claude CLI 等 Agent 时，应自行准备完整且兼容的系统提示词，先限定渠道验证多轮对话和工具调用，不建议直接全局启用。

普通渠道和 OAuth 订阅账号的连通性测试应用同一套规则，测试界面填写的用户提示词保持不变。协议探测、IQ 与指纹检测保留专用提示词，不应用此配置。模型列表查询也不涉及提示词替换。

该功能不修改限流分类、重试或账号冷却，不保证消除上游 429。

## 管理接口

管理员可通过 GET /admin/api/system-prompt-settings 读取配置，通过 PUT 同一路径保存整份配置。写入沿用管理员会话及 CSRF 保护，配置最大 64KB。响应包含 enabled、rules、updatedAt；updatedAt 由服务端生成。

规则字段为 id、name、enabled、scope、protocols、channelIds、priority、action、prompt。scope 使用 global、protocols、channels、channel_protocols；action 使用 replace 或 preserve。Chat Completions 的协议标识为 chat_completions，其他标识为 messages、responses、gemini。

受限作用域必须选择目标，替换规则必须填写非空正文，协议和渠道必须有效。配置持久化于 PostgreSQL，提交成功后发布本实例的新快照；读取失败不会静默回退为透传。沿用单实例部署边界，不增加跨实例配置同步。管理员审计记录修改动作，不记录提示词正文。
